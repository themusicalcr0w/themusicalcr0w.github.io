THE ENGINEERING

A small app with plenty of moving parts.

01

Coordinate the windows

The manager reconciles live windows with saved configuration. Removing a pet compacts the saved slots so runtime instances and stored data stay aligned.

02

Respect the desktop

Window placement accounts for display scaling, monitor bounds, and usable screen space. Resizing preserves the center where possible; moving monitors preserves relative horizontal placement.

03

Keep settings independent

Each pet retains its species, variants, colors, opacity, scale, height, and monitor. Separate animation resources prevent one pet’s visual changes from affecting another.

04

Work with native platforms

A C# bridge implements Windows taskbar behavior, X11 skip-taskbar and skip-pager properties, and macOS accessory-app behavior. Tray controls and autostart support complete the workflow.

What the project demonstrates

PokePet brings together multi-window coordination, persistent configuration and native operating-system integration. Each companion owns its settings and animation state, while a central manager handles its lifecycle. The project shows how those pieces work together in a responsive desktop application.
